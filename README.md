# نظام إدارة خريجي جامعة البطانة

## المميزات
- لوحة تحكم وإحصائيات حسب الأقسام (بطاقات متجاوبة).
- بحث متقدم، عرض تفصيلي، إضافة/تعديل/حذف (مع زر «جلب البيانات» قبل التعديل).
- استيراد وتصدير Excel، ونسخة احتياطية ZIP.
- تقرير PDF للخريج بالشعار وخط عربي.
- مستخدمون وصلاحيات (مدير / موظف / عرض فقط) مع تغيير كلمة المرور وسجل تدقيق.
- بوابة استعلام عامة للخريج برقم التسجيل.
- واجهة عربية RTL متجاوبة: حاسب، تابلت، هاتف.

## التشغيل محلياً
```bash
pip install -r requirements.txt
python app.py        # ثم افتح http://localhost:7860
```
المستخدم الافتراضي: `admin` / `1234` — **غيّر كلمة المرور فوراً** (تبويب المستخدمون)
أو حدّد `ADMIN_PASSWORD` كمتغير بيئة قبل التشغيل.

## النشر على استضافة مجانية

### الخيار 1: Hugging Face Spaces (الأسهل)
1. أنشئ Space جديداً واختر **Docker** (أو ارفع الملفات كما هي؛ ملف README يحتوي الإعداد).
2. ارفع كل ملفات المشروع.
3. من Settings ← Variables and secrets أضف Secret باسم `ADMIN_PASSWORD` بكلمة مرور قوية.

### الخيار 2: Render / Railway / Koyeb
- ارفع المشروع إلى GitHub، وأنشئ Web Service من Dockerfile (أو Build: `pip install -r requirements.txt`، Start: `python app.py`).
- أضف المتغير `ADMIN_PASSWORD`. المنفذ يؤخذ تلقائياً من `PORT`.

### ⚠️ حفظ البيانات
الاستضافات المجانية غالباً **تمسح الملفات عند إعادة التشغيل أو الخمول**، فترجع البيانات لما في `graduates.xlsx`. لذلك:
- صدّر Excel ونسخة احتياطية بشكل دوري من تبويب «Excel والتقارير»، وأعد الاستيراد عند الحاجة.
- أو حدّث `graduates.xlsx` في المشروع بأحدث نسخة قبل كل نشر.
- إن وفّرت الاستضافة قرصاً دائماً فاضبط `DATA_DIR` على مساره (مثل `/data`).

## متغيرات البيئة
| المتغير | الوظيفة |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور المدير (تُطبَّق عند كل تشغيل) |
| `DATA_DIR` | مجلد قاعدة البيانات والصور (افتراضي: مجلد المشروع) |
| `PORT` | منفذ التشغيل (افتراضي 7860) |

## النشر على Render — الطريقة المباشرة
- ارفع محتويات هذا المجلد إلى مستودع GitHub بحيث يكون `Dockerfile` في **جذر المستودع** وليس داخل مجلد فرعي.
- في Render اختر **New → Web Service** ثم اختر مستودع GitHub.
- اختر **Docker** واترك مسار Dockerfile: `./Dockerfile`.
- أضف متغير البيئة `ADMIN_PASSWORD` وضع كلمة مرور قوية للمدير.
- اترك Render يحدد `PORT` تلقائياً؛ التطبيق يستمع على `0.0.0.0` ويقرأ قيمة `PORT`.
- بعد نجاح النشر افتح رابط الخدمة من Render.
- إذا ظهر Build Failed، افتح **Logs → Build**. وإذا ظهر Runtime/Health Check Failed، افتح **Logs → Deploy**.
